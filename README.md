# BharatYatra AI — Smart India Tourism Planner

A premium, browser-first India travel planner built with React, Vite, Tailwind CSS and a local destination dataset. It has no accounts, API keys, paid services, or backend dependency.

## What’s included

- Explore all **28 states and 8 Union Territories**
- **108 curated destinations** in `src/data/destinations.json`
- Full-text search plus state, region, and experience filters
- Individual destination pages with practical travel information
- Rule-based recommendation engine that scores places by region, interests, budget, and trip duration
- Day-wise itinerary creation and INR budget breakdown
- English/Hindi user interface
- Favorite places and saved trips stored only in `localStorage`
- Print-ready itineraries and responsive mobile navigation
- A small service worker for offline use after the app has loaded

## Optional ElevenLabs voice

YatraSathi can read every assistant reply aloud. If ElevenLabs is configured, it uses high-quality multilingual speech through a protected serverless endpoint; otherwise it falls back to the device’s built-in browser voice.

1. Copy `.env.example` to `.env.local` for local development, or create the same variables in your Vercel project settings for deployment.
2. Add `ELEVENLABS_API_KEY` and optionally choose `ELEVENLABS_VOICE_ID`.
3. Redeploy the Vercel project. The key is only read by `api/voice.js` and is never included in browser code.

ElevenLabs bills text-to-speech usage according to the plan on the connected account. Keep the feature optional if you need a completely free, offline-only deployment.

## Run locally

Requirements: Node.js 20 or newer and npm.

```bash
npm install
npm run dev
```

Vite will print a local URL, usually `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

The optimized static site is created in `dist/`.

## Deploy

This is a static single-page app. Deploy the contents generated by `npm run build` to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any static host.

For hosts that need an SPA fallback, configure unknown routes to serve `index.html`, so direct links such as `/destination/hampi` continue to work.

## Data and privacy

- Destination records are local in `src/data/destinations.json`; the planner works without an API or API key.
- Favorites, language selection, and saved plans stay in the current browser through `localStorage`.
- Photos are progressive visual enhancements loaded from Unsplash; the planner, browsing dataset, recommendations, budgets, and saved plans remain usable without them.
- Clear site data in your browser to remove locally saved trips and favorites.

## Project structure

```text
src/
  components/     Reusable navigation, filters, and destination cards
  context/        App-wide language and local saved-item state
  data/           Regions, translations, and 108-place JSON dataset
  pages/          Home, explore, planner, saved trips, detail page
  utils/          Storage, recommendation, itinerary, budget helpers
public/           Service worker and web app manifest
```
